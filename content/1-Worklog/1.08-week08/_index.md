## Objectives

* Design a secure and scalable VPC network topology.
* Configure subnets, route tables, NAT gateways, and security groups.
* Implement connectivity patterns such as VPC peering or Transit Gateway.
* Review network security and traffic flow.

## Suggested tasks

| Day | Task | Notes |
|-----|------|-------|
| 1 | Design the VPC layout with public and private subnets | Include service isolation and NAT/IGW |
| 2 | Create route tables, NACLs, and security groups | Enforce least-privilege networking |
| 3 | Enable VPC peering or Transit Gateway for multi-VPC traffic | Validate routes and access control |
| 4 | Configure VPN, Direct Connect, or a site-to-site connectivity simulation | Document the network topology |
| 5 | Audit network traffic and secure ingress and egress paths | Use VPC Flow Logs where available |
| 6 | Document the network design and tradeoffs | Capture best practices and limitations |

## Key achievements

* Built a resilient VPC design with proper segmentation.
* Implemented secure routing and managed outbound access with NAT.
* Connected multiple VPCs or environments for cross-service traffic.
* Documented the network architecture and security assumptions.
