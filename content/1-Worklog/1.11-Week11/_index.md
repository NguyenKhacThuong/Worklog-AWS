## Goals

* Improve infrastructure automation with repeatable patterns.
* Build Terraform modules, reusable CI/CD workflows, and testing pipelines.
* Explore GitOps practices for deployment and environment promotion.
* Review rollback, blue/green, or canary deployment strategies.

## Suggested tasks (by day)

| Day | Task | Notes |
|-----|------|-------|
| 1 | Refactor IaC into reusable modules and parameterized templates | Share code across environments |
| 2 | Add automated validation and unit testing for infrastructure | Use Terraform fmt, validate, and plan checks |
| 3 | Build a GitOps-style workflow for environment promotion | Use branches, pull requests, or repository separation |
| 4 | Implement deployment strategies such as blue/green or canary | Reduce risk during releases |
| 5 | Add rollback and drift detection processes | Prepare recovery steps and alerts |
| 6 | Document automation patterns and operational workflow | Capture how deploys are triggered and audited |

## Achievements

* Created reusable automation modules and testable deployment pipelines.
* Applied GitOps principles for safer environment promotion.
* Implemented release strategies and rollback readiness.
* Documented automation patterns and operational playbooks.
