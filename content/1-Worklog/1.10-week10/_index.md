## Goals

* Explore AWS data services for storage, analytics, and query.
* Implement data lifecycle, archival, and access patterns.
* Build a small analytics pipeline using Athena or Glue.
* Review cost optimization for data workloads.

## Suggested tasks

| Day | Task | Notes |
|-----|------|-------|
| 1 | Define data storage patterns with S3 and lifecycle policies | Organize raw, processed, and archive tiers |
| 2 | Configure data catalog and query layer with Athena or Glue | Validate schema and partitioning |
| 3 | Build analytics queries or reports from sample data | Measure query speed and cost |
| 4 | Explore serverless data ingestion with Kinesis or S3 events | Automate data pipeline steps |
| 5 | Tune storage class and retention for cost efficiency | Use Intelligent-Tiering, Glacier, lifecycle rules |
| 6 | Document analytics architecture and results | Capture what worked and what can improve |

## Achievements

* Designed data storage and lifecycle management for analytics.
* Built query/reporting capabilities using managed AWS data services.
* Improved cost efficiency through storage class and retention tuning.
* Documented the end-to-end data workflow and lessons learned.
