## Objectives

* Explore AWS data services for storage, analytics, and querying.
* Implement data lifecycle, archival, and access patterns.
* Build a small analytics workflow using Athena or Glue.
* Review cost optimization for data workloads.

## Suggested tasks

| Day | Task | Notes |
|-----|------|-------|
| 1 | Define data storage patterns with S3 and lifecycle policies | Organize raw, processed, and archive tiers |
| 2 | Configure the data catalog and query layer with Athena or Glue | Validate schema and partitioning |
| 3 | Build analytics queries or reports from sample data | Measure query speed and cost |
| 4 | Explore serverless data ingestion with Kinesis or S3 events | Automate pipeline steps |
| 5 | Tune storage classes and retention to improve cost efficiency | Use Intelligent-Tiering, Glacier, and lifecycle rules |
| 6 | Document the analytics architecture and results | Capture what worked and what can be improved |

## Key achievements

* Designed data storage and lifecycle management for analytics use cases.
* Built query and reporting capabilities using managed AWS data services.
* Improved cost efficiency through storage-class and retention tuning.
* Documented the end-to-end data workflow and lessons learned.
