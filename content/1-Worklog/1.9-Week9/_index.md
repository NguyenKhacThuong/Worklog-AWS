## Goals

* Explore serverless services for application hosting.
* Build event-driven workflows using Lambda, API Gateway, and EventBridge.
* Evaluate managed data stores such as DynamoDB and S3 for serverless apps.
* Automate deployment and testing for serverless resources.

## Suggested tasks (by day)

| Day | Task | Notes |
|-----|------|-------|
| 1 | Design a serverless API with API Gateway and Lambda | Define endpoints, methods, and authorization |
| 2 | Implement DynamoDB or S3-backed storage for serverless flows | Use best practices for partition keys and performance |
| 3 | Configure EventBridge or SNS for asynchronous events | Build event-driven triggers |
| 4 | Deploy serverless stack with IaC and test end-to-end | Validate cold start, retries, and error handling |
| 5 | Enable observability for Lambda functions | CloudWatch metrics, logs, and X-Ray traces |
| 6 | Document serverless architecture and retry behavior | Capture deployment notes and limitations |

## Achievements

* Built a lightweight event-driven application using serverless AWS services.
* Connected API Gateway, Lambda, and event sources for async workflows.
* Implemented managed persistence with DynamoDB or S3.
* Documented serverless deployment and operational considerations.
